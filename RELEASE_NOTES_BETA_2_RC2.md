# Beta 2 RC2 Release Notes

This release converts several passive displays into working navigation controls.

- Fixed map exploration being overridden by follow mode.
- Added zoom-event detection and explicit Resume behavior.
- Removed Jesse demo mode.
- Added destination autocomplete with location-biased suggestions.
- Added Edit Route.
- Added Route to This Stop.
- Recommended shutdown now displays distance ahead rather than off-route distance.
- Recalibrated long-distance drive time and ETA estimates.
- Preserved direction-facing navigation camera.
